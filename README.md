# Sam's Omnifood

Welcome to **Sam's Omnifood**! This is a modern web application for a fictional food delivery service, featuring beautiful designs and seamless user experiences.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used
- React
- Vite
- Vanilla CSS
