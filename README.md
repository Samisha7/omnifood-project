# Omnifood

A modern, responsive food delivery website built with clean HTML, CSS, and JavaScript. Omnifood is a smart food subscription service that delivers personalized meals to your door.

## 🌟 Features

- 🍽️ **Food Subscription Service** - Choose from a variety of personalized meal plans
- 📱 **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- 🎨 **Modern UI/UX** - Beautiful and intuitive user interface with smooth animations
- 🔍 **Featured Meals** - Browse popular meal options
- 👨‍🍳 **Chef Profiles** - Learn about the talented chefs preparing your meals
- 📦 **Meal Plans** - Select from various subscription options
- 💳 **Easy Booking** - Simple and secure meal ordering process
- ✉️ **Newsletter Signup** - Stay updated with latest offers and recipes
- 🎯 **Call-to-Action** - Clear conversion-focused design

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Custom CSS with responsive design
- **Responsive Framework**: Mobile-first approach
- **Version Control**: Git

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, etc.)
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Samisha7/omnifood-project.git
cd omnifood-project
```

2. Open the project in your browser:
   - Simply open `index.html` in your web browser, or
   - Use a local server (recommended):
   
   **Using Python 3:**
   ```bash
   python -m http.server 8000
   ```
   
   **Using Node.js (http-server):**
   ```bash
   npm install -g http-server
   http-server
   ```

3. Navigate to `http://localhost:8000` in your browser
